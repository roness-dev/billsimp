# BillSimp

**BillSimp** is a simple invoicing system for freelancers and independent professionals.

## 📦 Features

- User Login & Registration
- Create and Download Invoices
- Generate Quotations
- Convert Quotes to Invoices
- Send Invoices via Email
- View Client Statements
- Basic Accounting (Income/Expenses)

## 💻 Tech Stack

- PHP 8.1
- MySQL
- HTML, CSS, Bootstrap
- jsPDF (for PDF generation)
- PHPMailer (for email sending)

## 🚀 Getting Started

1. Install XAMPP
2. Clone or copy this project into `C:\xampp\htdocs\billsimp`
3. Create a database `billsimp_db` in phpMyAdmin
4. Configure `config/db.php` with your database settings
5. Start Apache and MySQL
6. Open browser and go to: `http://localhost/billsimp`
