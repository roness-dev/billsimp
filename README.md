# BillSimp

BillSimp

BillSimp is a simple and modern invoicing system for freelancers, small businesses, and independent professionals. It helps manage invoices, payments, clients, quotes, and email communications efficiently.

📦 Features

User Login & Registration

Dashboard with quick stats: total invoices, payments received, outstanding payments, emails sent

Create, Edit, and Download Invoices

Generate Quotations and convert quotes to invoices

Send Invoices via Email

View Client Statements & Payments

Recent Activity Tracking: recent invoices and email logs

Basic Accounting: income and outstanding payments tracking

Settings & Preferences: update profile, change password, enable/disable email notifications, switch light/dark theme

Responsive Design: desktop tables and swipeable cards for mobile

📊 Dashboard Features

Charts for Payments vs Outstanding

Chart for Invoice Trends (Last 6 Months)

Quick links to create invoices and view statements

💻 Tech Stack

PHP 8.1

MySQL

HTML, CSS, Bootstrap 5

JavaScript, Chart.js

jsPDF (for PDF invoice generation)

PHPMailer (for sending emails)

🚀 Getting Started

Install XAMPP or any local PHP & MySQL environment

Clone or copy this project into your web directory, e.g., C:\xampp\htdocs\billsimp

Create a MySQL database billsimp_db using phpMyAdmin or command line

Configure database connection in includes/db.php

Start Apache and MySQL services

Open your browser and go to: http://localhost/billsimp

🛠 Directory Overview

index.php – Dashboard

invoices.php – Create & manage invoices

payments.php – View payments received & outstanding

quotes.php – Create quotes

statements.php – Client statements

clients.php – Client management

email.php – Send emails

settings.php – User profile & preferences

includes/db.php – Database connection

assets/ – CSS, JS, images`
